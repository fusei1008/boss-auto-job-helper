# BOSS 直聘求职助手 (Jev 深度研判·智能低频防封版)

[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](./LICENSE)
[![GitHub Release](https://img.shields.io/github/v/release/fusei1008/boss-auto-job-helper)](https://github.com/fusei1008/boss-auto-job-helper/releases/latest)
[![Tests: 55 Passed](https://img.shields.io/badge/Tests-55%20Passed-brightgreen.svg)](./test)

一个运行在浏览器里的 BOSS 直聘智能求职辅助脚本（单文件 Userscript，零依赖）。

既支持**全行业通用关键词规则初筛**，更深度集成了 **TypeSafe Jev 认知决策模型**。通过大模型语义理解解决传统脚本“误杀好岗位、漏放外包坑、打杂冒充研发”等痛点，实现**真研发深度量化、虚假陷阱一票否决、S/A/B 战略择优投递**。

核心设计目标是**低频、慢速、像真人**：不追求一键盲投几百家，而是用接近人工的节奏稳定筛选和沟通，最大限度保护账号安全。

> ⚠️ 使用前请先阅读 [风险与免责](#风险与免责)。

## 🌟 核心特性与亮点

### 1. 🧠 Jev 智能多维语义研判（革命性升级）
传统关键词脚本往往存在两大硬伤：
- **误杀**：JD 里写“本公司集研发、生产、销售于一体”或“五险一金+补充商业保险”，因包含“销售”“保险”等排除词而被直接跳过；
- **漏杀**：挂名“算法工程师/研发助理”，实际工作是数据清洗、设备擦洗打杂；或者挂靠劳务中介、先交费招转培。

接入 **TypeSafe Jev** 后，系统在代码端抓取纯净职位描述，进行 **6 维度正交语义研判**：

| 研判维度 | 指标类型 | 判定逻辑与准则 |
| --- | --- | --- |
| **对口程度 (fit)** | Score (0~3) | 严格对照用户画像。0=无关/非技术岗，1=同行业但技术方向错位，2=相近可转，3=核心主修专长直接对口 |
| **研发深度 (depth)** | Score (0~2) | 0=设备清洗/流水线/数据录入打杂，1=常规SOP/成熟管线日常运行，2=独立探索/实验设计/前沿算法核心研发 |
| **劳务派遣 (dispatch)** | Noul (概率) | 识别劳务中介、外包驻场、与第三方人力公司签合同等迹象，≥0.7 直接一票否决 |
| **收费培训 (paid_training)** | Noul (概率) | 识别招转培、入职押金、先培训后上岗贷款等陷阱，≥0.7 直接一票否决 |
| **伪装销售 (sales_in_disguise)** | Noul (概率) | 识别挂名研发/技术支持实则背负销售获客指标的岗位，≥0.7 直接一票否决 |
| **排斥约束 (excluded)** | Noul (概率) | 对照用户画像中声明的“绝对排除”项（如动物房打杂、车间普工），命中即淘汰 |

### 2. 💎 S / A / B 战略择优与分级流转
每日沟通额度宝贵，脚本不会见岗就投：
- **💎 S 级（核心对口）**：直接对口（fit ≥ 2.5）且具备实质研发深度（depth ≥ 1.5），高优自动沟通；
- **⭐ A 级（对口推荐）**：直接对口的标准工程师/研究员岗位，自动沟通；
- **🔹 B 级（相近备选）**：属于相近交叉领域但有一定转岗成本，默认记为**备选（hold）**不自动投递，可在面板手动开启；
- **🟡 待复核（review）**：当 Jev 对是否对口或可疑外包把握不足时，标记为待复核，交由人工决断；
- **🚫 拒绝（reject）**：命中红线陷阱或研发深度低于预设门槛直接跳过。

### 3. 🧪 校准模式 (Dry-Run)
- 勾选后，脚本在页面正常巡检、点开详情、调用 Jev 研判并打上卡片徽标，**但绝不点击沟通按钮、不消耗每日额度**；
- 极大方便新手导入个人画像后，先跑 30~50 个岗位查看打分表现，满意后再切正式投递。

### 4. 📊 本地决策记录与 JSON 导出
- 内置决策记录流水（本地保留最近 200 条），记录每个岗位的打分明细、概率、直达链接与 API 预估花费；
- 支持一键只查看“待复核/备选”岗位，或一键下载结构化 JSON 文件供离线审计。

### 5. 🐢 超低频真人慢速巡检
- 单次投递随机间隔（默认 45~90 秒，硬下限 20 秒），每沟通 3 人强制真人化休整 60~120 秒；
- 严格遵循平台原生逻辑：点击“立即沟通”由平台发送官方预设招呼语，弹窗时自动选择“留在此页”。

### 6. 🔓 本地薪资字体还原与硬规则
- **字体解密**：BOSS 采用自定义字体加密薪资（映射到 Unicode 私用区 `0xE031~0xE03A`），脚本在本地还原为真实数值进行薪资下限过滤；
- **学历与年限前置分流**：卡片标签要求经验 ≥3 年或博士学历时，直接在代码层快速跳过，节省模型调用成本。

## 🛠️ 安装与快速上手

### 步骤 1：安装脚本
1. 在浏览器安装扩展：[Tampermonkey（油猴）](https://www.tampermonkey.net/) 或 Violentmonkey；
2. 前往 [Releases 最新发布页](https://github.com/fusei1008/boss-auto-job-helper/releases/latest) 下载 `BOSS-Auto-Job-Helper.user.js`；
3. 将 `.user.js` 文件拖入浏览器，点击油猴的“安装”按钮。

### 步骤 2：进入求职页面
打开 [BOSS 直聘](https://www.zhipin.com/) 并登录，进入**职位推荐页**或**搜索结果页**（左右分栏布局：左侧岗位列表，右侧职位详情）。右下角将自动浮现控制面板：

```
+-------------------------------------------------------+
| 🧬 BOSS 智能求职助手                           [收起] [×] |
+-------------------------------------------------------+
| [▶ 开始低频投递]   [⏸ 暂停]   [⏹ 停止]               |
| 成功: 0  |  跳过: 0  |  失败: 0  |  剩余配额: 40       |
| 状态: 低频助手已就绪...                                 |
+-------------------------------------------------------+
| [🧠 Jev研判]  [📋 规则配置]  [🎯 目标直投]  [📜 运行日志] |
+-------------------------------------------------------+
```

### 步骤 3：配置 Jev 模型与个人画像
切换到 **🧠 Jev研判** 选项卡：
1. **勾选【开启研判】**；
2. **填写 API Key**：
   - **TypeSafe 直连**：端点 `api.typesafe.ai`，钉死高精度模型 `jev-1.13.0`（输入约 $0.042/M tokens，成本极低）；
   - **OpenRouter**：填入 `sk-or-...` 开头的 Key，自动路由到 `typesafe/jev-1.13`；
   - 点击 **【⚡ 测试连接】** 确认密钥与网络畅通。
3. **填写个人画像 (Jev 锚点)**：
   > 💡 **写好画像是精准研判的关键**！建议写清：学历层次、真正精通的技术/工具栈、期望细分方向，并另起一行注明“绝对排除：...”。
   ```text
   求职意向：生物研发工程师、分子生物研究员、蛋白表达纯化研发助理。
   学历与技能：生物学相关硕士。精通分子克隆、质粒构建、重组蛋白表达与纯化（AKTA/FPLC）、抗体工程或多肽合成。
   核心偏好：正规生物医药企业或研发机构的核心技术岗位。
   绝对排除：劳务派遣外包、医药电话销售、医药招商、动物房日常清洗打杂、纯流水线车间操作工。
   ```
4. **推荐初次使用开启【🧪 校准模式】**：先点击开始跑一轮，打开【📊 决策记录】抽查打分情况；确认满意后再取消勾选，进入正式投递。

## ⚙️ 面板分区功能说明

### Tab 1: 🧠 Jev研判
- **最低研发深度 (0~2)**：默认 `1.0`。低于此分的打杂/清洗/低端录入岗位直接淘汰；
- **陷阱可疑阈值 (0~1)**：默认 `0.35`。中介外包/挂名销售概率高于此值转人工复核，达 `0.7` 直接拒绝；
- **自动投递最低等级**：支持选择 `仅 S 级`、`S + A 级（推荐）` 或 `S + A + B 级`；
- **📊 决策记录**：弹窗查看每个候选岗位的多维打分矩阵与结论，支持导出完整 JSON。

### Tab 2: 📋 规则配置
- **方向预设**：内置 3 大理工科高频方向（生物医药研发、生信/AI计算、质检理化分析），一键载入关键词与门槛；
- **关键词初筛**：支持包含词与排除词。英文短词（如 `AI`、`QA`）按整词匹配，中文按子串匹配；
- **硬规则门槛**：
  - 安全投递随机间隔：默认 `45 ~ 90` 秒（硬下限 20 秒）；
  - 每日投递上限：默认 `40` 人；
  - 最低月薪：低于设定值跳过（面议或未标注时不跳过）；
  - 经验过滤：如设置 `≥3 年`，则卡片标有 3-5年、5-10年时直接跳过；
  - 博士过滤：可一键跳过要求博士学历的岗位。

### Tab 3: 🎯 目标直投
- 点击任意职位卡片，可一键在搜狗微信检索该公司最新的公众号招聘推文与 HR 直投邮箱，或在爱企查查询官网；
- 支持一键导出已投递公司名单。

### Tab 4: 📜 运行日志
- 实时打印当前卡片的筛选原因、Jev 打分详情、网络重试状态与风控提示。

## 🛡️ 网络故障与健壮性设计

脚本对网络抖动与平台限制做了全面的防崩溃处理：
- **限流退避**：遇到 `429 Too Many Requests` 或网络超时，采用指数退避重试（2s -> 5s）；
- **永久错误熔断**：遇到 `402 Payment Required`（余额不足）、`401`（Key 无效）立即中止投递并蜂鸣报警，**绝不偷偷降级为无脑盲投**；
- **连续异常熔断**：连续 5 次页面加载或 DOM 交互异常自动暂停保护；
- **风控智能识别**：自动探测图形滑块、极验验证码、访问过于频繁、登录拦截等特征，发现后立即停机并弹窗提醒人工处理。

## 🔒 隐私与安全承诺

- **无隐私上传**：脚本为纯客户端单文件运行，不包含任何第三方追踪分析或数据回传代码；
- **凭据本地存储**：Jev API Key、个人画像与投递历史仅加密保存在浏览器的 Tampermonkey 存储中；
- **非破解**：不逆向、不篡改 BOSS 直聘加密协议，仅模拟人工合法界面的慢速操作。
