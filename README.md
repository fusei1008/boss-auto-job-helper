# BOSS 直聘求职助手（通用版）

一个运行在浏览器里的 BOSS 直聘求职辅助脚本。**不限专业方向**——互联网、算法、硬件、机械、生物医药、财务、销售、职能、设计、供应链、教育……都能用，关键词和招呼语完全可自定义。

核心设计目标是**低频、慢速、像真人**：不追求一键投几百家，而是用接近人工的节奏稳定筛选和打招呼，尽量降低账号被风控的概率。

> ⚠️ 请先读 [风险与免责](#风险与免责)。

## 功能

| 功能 | 说明 |
| --- | --- |
| 🧠 Jev 智能语义研判 | 接入 TypeSafe Jev (jev-1.13.0) / OpenRouter 决策模型，精准识别专业对口、量化研发深度，多维交叉验证 |
| 🚫 招聘陷阱一票否决 | 严密识破劳务派遣/外包驻场、招转培/收费培训、挂名技术实为销售及触犯个人排斥约束等陷阱特征 |
| 💎 S/A/B 战略择优 | S 级核心对口、A 级对口推荐、B 级相近备选，可配置自动投递最低门槛，不浪费宝贵的每日额度 |
| 🧪 校准模式 (Dry-Run) | 只研判打标、不点击沟通、不耗费额度，配合决策记录流水可一键抽查打分或导出 JSON 审计 |
| 🐢 低频防封投递 | 单次投递随机间隔（默认 45~90 秒，硬下限 20 秒），每 3 人强制休整 60~120 秒，每日配额可设 |
| 🔓 薪资字体解密 | BOSS 用自定义字体把数字渲染到私用区码点（U+E031~U+E03A），脚本在本地还原为真实数字，用于薪资门槛过滤 |
| 🔍 经验/学历硬规则 | 自动识别卡片经验年限与博士学历要求，超限直接跳过，减轻模型认知负担 |
| ✅ 沟通结果确认 | 点击「立即沟通」后等待平台反馈，区分「已建立沟通 / 已达上限 / 风控验证 / 未确认」四种结果 |
| 🛡️ 风控自动保护 | 识别验证码、滑块、异常访问、登录墙等特征后自动暂停并提示人工处理 |
| 📋 投递记录导出 | 自动记录已沟通的公司与岗位，支持一键复制或导出 JSON |
| 🖱️ 面板可拖拽 | 位置记忆，可收起/隐藏，隐藏后可从脚本管理器菜单重新唤出 |

## 安装

1. 安装脚本管理器：[Tampermonkey](https://www.tampermonkey.net/) 或 Violentmonkey。
2. 新建脚本，把 `BOSS-Auto-Job-Helper.user.js` 的全部内容粘贴进去并保存。
   （或把 `.user.js` 文件直接拖进浏览器窗口，脚本管理器会弹出安装页。）
3. 打开 `https://www.zhipin.com/`，进入 **推荐** 或 **搜索结果** 页，右下角会出现操作面板。

> 面板没出现？点击脚本管理器的图标 → 对应脚本 → 菜单里的「显示 BOSS 低频求职面板」。

## 使用

1. 在页面上进入职位**列表页**（左右分栏那种，左边列表右边详情）。推荐流和搜索结果页都支持。
2. 面板里选**方向预设** → 点【应用】，或自己手填包含/排除关键词。
3. 调好**投递间隔**和**每日上限**，点【▶ 开始低频投递】。
4. 脚本会逐张评估卡片：过滤 → 点开详情核验 → 点击沟通 → 确认结果 → 随机等待 → 下一张。

### 参数说明

| 参数 | 默认 | 说明 |
| --- | --- | --- |
| 安全投递间隔 | 45 ~ 90 秒 | 每次成功投递后的随机等待。最小不能低于 20 秒 |
| 每日上限 | 40 人 | 达到即自动停止，建议 30~50 |
| 最低月薪 | 随预设 | 单位 K。低于该值跳过；`0` 表示不限。日薪/时薪/面议不做过滤 |
| 自动排除实习 | 开 | 标题或标签含「实习」即跳过 |
| 自动发送求职介绍 | 开 | 平台弹出自定义招呼语输入框时，自动填入并发送 |

### 关键词匹配规则

- 分隔符：空格、逗号、中文逗号、顿号、分号、竖线都能用。
- **纯英文/数字**关键词（`AI`、`QA`、`Java`、`C++`）按**整词**匹配，不会把 `email` 里的 `ai` 误判成命中。
- **含中文**的关键词按**子串**匹配（`后端` 能命中「高级后端开发」）。
- **包含关键词留空 = 不按方向筛选**，只受排除词约束，适合「不限方向、只求打招呼」的用法。
- 排除词优先级最高，命中即跳过。

### 招呼语占位符

```
您好！我对贵司的「{title}」岗位很感兴趣，我在 XXX 方面有 N 年经验。
```

- `{title}` / `{岗位}` → 当前岗位名
- `{company}` / `{公司}` → 当前公司名

想带上自己的名字和联系方式，直接在招呼语里写死即可。

### 添加自己的方向

打开脚本，找到 `const PRESETS = { ... }`，复制任意一条改成自己的即可：

```js
my_direction: {
  name: "🎯 我的方向",
  includeKeywords: "关键词1, 关键词2, Keyword3",
  excludeKeywords: COMMON_EXCLUDE,          // 可复用通用排除词，也可整串自定义
  greetingText: "您好！我对「{title}」很感兴趣……",
  minSalaryK: 8
}
```

面板下拉框会自动出现新选项，不需要改 UI 代码。默认使用的预设由 `DEFAULT_PRESET_KEY` 决定。

## 开发

脚本是单文件、零依赖的原生 JS。所有页面选择器集中在 `SEL` 对象里——**BOSS 改版时只需要改这一处**。

```bash
node --check BOSS-Auto-Job-Helper.user.js   # 语法检查
node test/smoke-test.js                     # 跑基础冒烟测试
node test/verify.js                         # 跑 Jev 决策与状态测试
```

冒烟测试用最小 DOM 桩直接加载脚本本体，校验预设完整性、关键词匹配规则、薪资解密、配置迁移、招呼语占位符等纯逻辑，不需要浏览器。

### 提交前请注意

- 新增/修改预设后跑一遍 `node test/smoke-test.js`。
- 如果你改了 `@version`，**不要**在 `sanitizeSettings` 里加「版本变化就重置用户配置」的逻辑——那会把所有用户的配置清掉。
- 别提交自己的 `@homepageURL` 之外的私人信息（本地路径、内网地址、个人邮箱）。

- 本脚本通过模拟真人的低频操作辅助筛选与打招呼，**不保证不被风控**。BOSS 直聘的用户协议可能不允许自动化操作，使用前请自行评估账号风险，**后果自负**。
- 脚本已内置风控识别与自动暂停，但风控策略随时可能变化。检测到验证码/滑块时请手动完成，不要试图绕过。
- 每日上限默认 40 人，是为了账号安全刻意压低的值。**调高上限会显著提高被封风险**，请谨慎。
- 本项目仅供个人求职效率提升与前端自动化技术学习交流使用，作者不对因使用本脚本造成的任何账号损失、数据损失或法律纠纷负责。
